## Что это
Кооперативный браузерный/десктоп 3D-квест для детей 10–14 лет и семьи.
Делают папа с дочкой вместе с ИИ. Жанр: добрый sci-fi приключение в духе
«Автостопом по галактике». 3 миссии (Земля → Космос → Планета), до 4 игроков.

## 🧒 Правила контента (ВАЖНО)
Игра ДЛЯ ДЕТЕЙ. Только приличный контент: без мата, жестокости ради
жестокости, страшного, рекламы вредных привычек. **Кровь и взрывы в
приключенческих количествах — МОЖНО** (комета, запуск ракеты, царапины).
Ориентир: «Disney/Pixar + добрый мультик». Подробнее — в README.md.

## Как запустить игру
1. Godot 4.6 (Standard, НЕ .NET): https://godotengine.org/download
   (универсальная сборка для Mac, работает на Intel и Apple Silicon)
2. Открыть проект: Import → `godot_project/project.godot`
3. Дождаться импорта ассетов (внизу справа), потом ▶️ (или F5)
4. Два игрока на одном ПК: **Debug → Customize Run Instances** → Add Instance
5. Создать комнату → код подставится в поле → второй игрок вводит код

## ⚠️ Грабли (проверено на практике — не наступать снова)
1. **GLB-модели Kenney/poly.pizza имеют внутренний offset** → раньше «уезжали».
   Чинится: для Kenney пропатчены translation→0; для персонажей —
   автонормализация роста по скелету (`player.gd::_normalize_model_height`).
2. **«Generate LODs» при импорте GLB ломает vertex colors** (чёрные модели).
   Отключено глобально в `project.godot [importer_defaults]`.
3. **Модели смотрят в +Z, «перёд» игрока −Z** → разворот модели на 180°.
4. **Строгая типизация GDScript**: `var x := abs(...)` падает «Variant».
   Использовать явные типы и `absf/maxf/lerpf/clampf`.
5. **Разные GLB — разный внутренний масштаб** → нельзя фикс-scale, только
   автонормализация по костям.
6. **Имена анимаций различаются** («Walk» vs «Walking», «Idle» vs
   «Attacking_Idle») → `player.gd::_pick_anim` (точное имя > суффикс > вхождение).
7. **Песочница Bash не видит ~/Downloads** (защита macOS). Чтобы дать мне
   файл — перенести его в папку проекта.
8. **Проверка перед коммитом:** `Godot --headless --import` (ловит ошибки
   парсинга). Чисто = пусто в выводе.
